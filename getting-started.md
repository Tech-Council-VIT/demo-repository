# Getting started

1. Use your own GitHub account and enable 2FA.
2. Accept the organisation invitation.
3. Join the team corresponding to your work.
4. Read the target repository README and contribution guide.
5. Install the project's toolchain.
6. Run the project and tests locally.
7. Pick a `good first issue` or ask the maintainer for a starter task.

Never share accounts or tokens. Request access through the team lead.
