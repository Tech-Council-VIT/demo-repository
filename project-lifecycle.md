# Project lifecycle

Every project needs:
- a named maintainer and backup maintainer;
- a problem statement and scope;
- reproducible setup instructions;
- issue tracking and milestones;
- tests appropriate to the project;
- a license and third-party asset review;
- deployment/maintenance instructions where applicable;
- a batch handover plan.

Lifecycle: Proposed → Approved → Active → Maintenance → Archived.

Archive projects that have no maintainer or viable maintenance plan. Document their final status.
