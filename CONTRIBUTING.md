# Contributing

1. Open or find an issue before significant work.
2. Create a focused branch (`feat/...`, `fix/...`, `docs/...`).
3. Follow formatting and test commands documented by the project.
4. Add or update tests and docs.
5. Open a pull request with a clear summary and validation notes.
6. Address review feedback.

Do not commit credentials, private data, generated build output or assets without redistribution rights.
