# Semester handover

- [ ] Confirm incoming and outgoing maintainers.
- [ ] Review organisation owners and team membership.
- [ ] Transfer maintainer responsibility through GitHub teams.
- [ ] Rotate secrets when personnel or access changes.
- [ ] Document active projects, deployment locations and outstanding issues.
- [ ] Record infrastructure dependencies and billing ownership.
- [ ] Review GitHub Apps, OAuth grants and outside collaborators.
- [ ] Publish a dated handover summary.
- [ ] Remove access that is no longer required.

Never put actual secret values in handover documentation.
